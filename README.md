# bm-export

Exported **Beatmeat** playback scenes, consumed at runtime by the iOS player
(`player-ios/` in the `bm` repo).

Generated by `scripts/export-projects.js` in the `bm` repo — **do not edit by hand**.

## Layout

```
manifest.json                     catalogue of all scenes
<project>/<scene>/project.json    engine config (controls, samplers, patterns, …)
<project>/<scene>/audio/*         the scene's audio samples (paths relative to project.json)
```

## How the app loads it

The player fetches `manifest.json` over HTTPS via jsDelivr's GitHub CDN:

```
https://cdn.jsdelivr.net/gh/jhnmeelr/bm-export@main/manifest.json
```

## Publishing an update (from the `bm` repo)

```bash
node scripts/export-projects.js          # regenerates ./export
cd export
git add -A && git commit -m "update export"
git push
```

jsDelivr caches `@main` for a while; to serve a fresh push immediately, pin the
app to a commit hash or purge via `https://purge.jsdelivr.net/gh/jhnmeelr/bm-export@main/…`.
